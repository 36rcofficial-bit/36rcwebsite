# 36RC – Chhattisgarh Riding Club website

React + Vite landing page.

## Chalane ke liye

```bash
npm install
npm run dev
```

## Content badalna

Saari details (naam, WhatsApp number, rides, FAQ) `src/config.js` me hain.
Wahan badlo, page apne aap update ho jayega.

## Live karne ke liye build

```bash
npm run build
```

`dist/` folder ready ho jayega.
